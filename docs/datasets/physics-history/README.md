# 물리학사 지식그래프 RAG 평가 데이터셋

지식그래프 기반 RAG 시스템이 엔티티 병합, 관계 추출, 다중 홉 추론, 계보 추적, 연대 비교, 집계, 문서에만 있는 사실 처리, 근거 없는 질문 거절을 얼마나 잘하는지 평가하기 위한 한국어 데이터셋이다.

## 범위

- **고대 자연철학**: 아리스토텔레스, 아르키메데스, 프톨레마이오스
- **과학혁명**: 코페르니쿠스, 갈릴레이, 케플러, 티코 브라헤, 뉴턴, 하위헌스
- **고전물리학**: 광학(영, 프레넬), 열역학(카르노, 줄, 헬름홀츠, 클라우지우스, 켈빈, 볼츠만, 슈테판), 전자기학(외르스테드, 데이비, 패러데이, 맥스웰, 헤르츠)
- **현대물리학**: 상대론(마이컬슨·몰리, 피츠제럴드, 로렌츠, 아인슈타인, 민코프스키, 에딩턴), 양자론(플랑크, 밀리컨, 러더퍼드, 보어, 드브로이, 하이젠베르크, 조머펠트, 파울리, 보른, 슈뢰딩거), 양자장론(디랙, 앤더슨, 램, 파인만, 슈윙거, 도모나가, 휠러), 해석 논쟁(EPR, 벨, 아스페)

## 품질 점검

- `questions.json`에 나오는 `fact_ids`는 모두 `facts.json`에 있다.
- 사실마다 주어와 목적어(별칭 포함)가 `docs`에 적힌 모든 문서에 실제로 등장하는지 스크립트로 검사했다. 서술 관계는 문서를 직접 읽고 대조했다.
- 집계 질문의 정답 집합이 문서에서 늘어나지 않게 했다. 예를 들어 문서 전체에서 1930년대 노벨상 수상자는 하이젠베르크, 슈뢰딩거, 디랙뿐이다.
- 부정 질문에 쓰인 대상(페르미, 볼츠만의 노벨상, 피르나우의 수상)은 어느 문서에도 나오지 않는다.
- 일부 연대는 관례적 표기를 따랐다. 영의 이중 슬릿 실험은 1801년, 노벨상은 수여 연도가 아니라 해당 연도 상 기준이다(하이젠베르크 1932년도 상은 1933년에 수여).
