# 2026-11-25 의사결정 로그

## D1. 파이프라인 연결 = 성공 연결 + 실패/예외 연결

- **문제**: 스테이지 사이 연결이 무조건이었다. 스테이지가 예외를 내도 로그 한 줄만 남기고 다음으로 넘어갔고, 결과가 0건이면 `/chat` 이 오류 판정 전에 돌아가 `has_error:false`·`strategy: unknown` 으로 "정보 없음" 답변을 냈다 (Milvus 컬렉션 없는 KB 에서 확인).
- **결정** (사용자, ATalk #50):
  - 카드 위쪽 화살표 = 정상(성공) 연결 → 다음 스테이지.
  - 카드 우하단 연결부 = 실패/예외 연결(`on_failure`, 뒤쪽 스테이지 id). 실패하면 그 스테이지로 넘어간다. 대상 스테이지는 실패했을 때만 실행되고, 성공하면 건너뛴다.
  - 실패 연결이 없으면 실패를 알리고 파이프라인을 멈춘다.
  - 실패 = 예외, 또는 그래프 스테이지가 근거(트리플·청크)를 하나도 찾지 못함.
  - 실패 연결이 있는 그래프 스테이지는 내부 문서 검색 대체(`graph_fallback`)를 끈다 — 대체를 파이프라인이 맡는다.
- **알림**: 응답에 `stage_failures` (스테이지·종류 error|empty·메시지·넘어간 스테이지). `has_error` 는 예외가 있을 때만. 결과가 없으면 답변 본문에 실패 스테이지와 이유를 적는다. 채팅 화면은 답변 아래에 ⚠ 줄로 표시.
- **저장**: 스테이지에 `id`·`on_failure`. 버전 비교 해시는 `id` 를 빼고 실패 연결을 대상 위치로 바꿔 계산한다 (화면이 붙이는 임의 id 로 '변경됨' 이 뜨지 않게).
- **Agentic 이 있는 파이프라인**: 실패 연결을 쓰지 않는다 (에이전틱이 스스로 순서를 정함). 화면에서도 연결부를 숨긴다.
- **영향**: 운영 중인 KB 파이프라인은 모두 검색 스테이지 1개라 동작 변화 없음 (실패 시 멈춤 = 기존과 같은 빈 결과, 대신 실패가 드러남).

## D4. LLM 근거 검증을 모든 관계로 (추출 품질 후속 B)

- **확대**: 방향 검증(`direction_audit`)에 `scope=all` — 같은 클래스 관계뿐 아니라 모든 관계를 원문 문장으로 판정. 한 번 정한 범위는 자동 증분 검증(재추출·그래프 변경 후)도 따른다.
- **근거 문장**: value·entity 규칙의 원래 표기로도 찾고('Availability' ← '가용성'), 목적어가 나오는 문장을 먼저 보인다.
- **자동 제외 조건** (실측으로 세 번 좁힘 — 아키텍처 KB):
  1. 1차: unrelated + 두 판정 일치 → 61건 제외, 원문에 있는 '가용성 긍정 효과' 까지 빠짐 (영어 정규화 값의 원문 문장을 못 찾음) → 전부 되돌림.
  2. 2차: + 근거 청크에 목적어 없음 → 29건, 사실은 맞고 근거 청크만 잘못 붙은 경우 섞임 → 되돌림.
  3. 3차: + 같은 문서 어디에도 목적어 없음 → 19건 중 18건 정확, 1건 오류(영어 목적어 'high domain complexity') → 되돌리고 **별칭 없는 영어 값은 사람 검토**로.
  - 최종: 같은 문서 어디에도 목적어(원래 표기 포함)가 없음 + 별칭 없는 영어 값 아님 + unrelated + 두 번째 판정도 none. 삭제는 triple 규칙(origin=auto_grounding)이라 되돌릴 수 있다.
- **방향 자동 뒤집기는 scope=all 에서 하지 않는다**: 정의 ~50개를 한 프롬프트에 넣자 '기반함' 정방향 13건을 reverse 로 판정·자동 뒤집기 → 되돌림. 묶음별 정의만 넣자 '기반함' 은 바로잡혔지만, '계승_발전'(정의: A 계승_발전 B = B 가 A 를 이어받음)은 관계 이름과 정의 방향이 엇갈려 계속 반대로 읽힘 → reverse 는 검토 목록만.
  - 후속 확인 필요: 11/16 같은 클래스 범위 자동 뒤집기 중 '양자역학 계승_발전 파동-입자 이중성' 등도 같은 문제일 수 있다. `계승_발전` 관계 이름을 정의 방향과 맞추는(예: `이어받아_발전됨`) 스키마 정리가 근본 해결.
- **결과**: 아키텍처 KB 18건 제외(원문 대조 정확), 물리학사 KB 0건. 회귀 아키텍처 12/14 그대로.
